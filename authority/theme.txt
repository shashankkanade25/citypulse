🗺️ Maps & Heatmaps

Base map: grayscale

No satellite view

Tooltips only on hover

Purpose:

Data clarity, not visual appeal

🧩 Component Rules (Strict)

✔ Buttons:

Primary: solid navy

Secondary: outline

Destructive: red outline only

✔ Inputs:

Border-based

No floating labels

Clear error messages

✔ Icons:

Functional only

Never decorative

🎛️ Dark Mode?

🔴 NO (for Admin)

Reason:

Government dashboards prioritize clarity

Dark mode increases misread risk in dense tables

Citizen site can have it — Admin should not.
